Alur cepat

  1. Siapkan file – drop file lagu (MP3/WAV/OGG/M4A) di Music Control, atau ambil dari Downloader.
  2. Atur – kalau lagu terlalu cepat, turunkan Speed (mis. 0.85×) dengan Pertahankan pitch aktif.
  3. Proses & dengarkan – tekan Proses, cek hasilnya di player.
  4. Kirim ke Uploader – file otomatis dijadikan MP3 ≤ 4 MB, lalu upload dan salin Asset ID.
  5. Masuk Music System – centang Otomatis tambahkan ke Music System; lagu langsung muncul di game (speed tetap 1× normal).

Tips lagu terlalu cepat

  • Speed 0.80–0.95× biasanya cukup. Aktifkan Pertahankan pitch agar suara tidak jadi berat.
  • Di Roblox kamu juga bisa memakai Sound.PlaybackSpeed, tapi memperbaiki file langsung membuat semua pemain mendengar versi yang sama.
  • Pakai bitrate 128 kbps agar lagu 4 menit tetap di bawah batas upload.

Informasi penting

  • Upload hanya untuk audio yang kamu miliki haknya atau berlisensi. Roblox memoderasi audio berhak cipta.
  • Roblox mewajibkan akun terverifikasi untuk upload audio dan API key Open Cloud dengan izin Assets.
  • YouTube / Spotify tidak didukung (melanggar syarat layanan & hak cipta).
  • Batas ukuran upload lewat Vercel ≈ 4.4 MB.
